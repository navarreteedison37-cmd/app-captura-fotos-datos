# 🌐 Versión Web - Captura de Fotos

## 🚀 Usar en Navegador

### Opción 1: En Línea (Más Fácil)
1. Haz clic aquí: https://navarreteedison37-cmd.github.io/app-captura-fotos-datos/web/
2. ¡Listo! Abre en tu navegador

### Opción 2: Local en tu PC
1. Descarga la carpeta `/web`
2. Abre `index.html` en tu navegador
3. ¡Listo!

---

## 📋 Características

✅ **Captura de Fotos**: Desde tu cámara (PC o celular)
✅ **Extrae Datos**: Automáticamente (manual si es necesario)
✅ **Guarda en Excel**: Descargable
✅ **Genera Word**: Plantilla personalizada
✅ **Sin servidor**: Todo en el navegador
✅ **Offline**: Funciona sin internet

---

## 🎯 Flujo

1. **Configuración**: Selecciona tipo de informe
2. **Seleccionar Word**: Carga tu plantilla (opcional)
3. **Foto 1**: Comprobante
4. **Foto 2**: Documento
5. **Datos**: Verifica o completa
6. **Excel + Word**: Descarga

## 🎓 Guía Rápida

### Primera vez:
1. Selecciona "Control de Espectáculo" o "Control de Inspección Laboral"
2. Carga archivo Word (si tienes)
3. Toma foto 1
4. Toma foto 2
5. Completa datos
6. ¡Listo! Descarga Excel y Word

### Varias capturas:
- Presiona "Nueva Captura"
- Repite pasos 3-5
- Todos los datos se guardan automáticamente

---

## 💾 Datos Guardados

Todo se guarda en tu navegador (LocalStorage).
No se envía a ningún servidor.

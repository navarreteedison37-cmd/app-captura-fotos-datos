# App Captura de Fotos y Datos

## Descripción
Aplicación móvil (APK) que captura fotos de documentos, extrae datos automáticamente con OCR, y genera reportes en Excel y Word.

## Características
- 📸 Captura de fotos desde celular
- 🤖 Extracción automática de datos con OCR
- 📊 Generación de reportes en Excel
- 📄 Generación de informes en Word
- 📱 Aplicación móvil (APK)
- 🌐 Panel web para visualizar datos

## Estructura del Proyecto
```
app-captura-fotos-datos/
├── mobile-app/          # Aplicación Android (APK)
├── backend/             # API Rest (Python/Flask)
├── frontend/            # Panel web
├── ocr-module/          # Módulo OCR
├── templates/           # Plantillas Word/Excel
└── docs/                # Documentación
```
